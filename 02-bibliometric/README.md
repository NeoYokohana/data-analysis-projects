# 自动驾驶领域文献计量与知识图谱分析

以 Web of Science 核心合集 2002—2026 年 25,538 篇文献为样本的领域知识结构分析。

## 结果

- 关键词共现（阈值 ≥5 次）：识别 **4 类**研究方向
- 作者合作（阈值 ≥3 篇）：识别 **6 大**合作团队，呈「小集中、大分散」格局
- 国家合作（阈值 ≥15 篇）：形成 **3 大**国家集群

结论：该领域研究经历「系统控制 → 机器学习 → 深度学习感知」三阶段迁移。
